# Drizzle + Supabase Migration

Minimal infrastructure package to create the `form_submissions` table in Supabase using Drizzle.

## Requirements

- Node.js 24+
- pnpm 9+

## Setup

```bash
cd packages/infrastructure/drizzle
pnpm install
cp .env.example .env
```

Edit `.env` and set your Supabase Postgres connection string:

```env
DATABASE_URL=postgresql://postgres:<PASSWORD>@db.<PROJECT_REF>.supabase.co:5432/postgres
```

## Generate and run migration

```bash
pnpm drizzle:generate
pnpm drizzle:migrate
```

`pnpm drizzle:generate` now does two things:

1. Generates migration with Drizzle.
2. Automatically prepends:

```sql
DROP TABLE IF EXISTS "form_submissions" CASCADE;
```

to the newest migration SQL file.

## Table created

- `public.form_submissions`

Key details:

- `emails` uses PostgreSQL `json` and stores a JSON array (example: `["a@x.com", "b@y.com"]`).
- `channel` is a required `text` column.
- File fields are nullable `text` columns intended for Supabase Storage path/URL.
- Includes `id` (`integer GENERATED BY DEFAULT AS IDENTITY` PK, auto-increment) and `created_at` (`timestamptz` default `now()`, defined as the last column).

## Re-run after schema changes

When you change `src/schema.ts`:

```bash
pnpm drizzle:generate
pnpm drizzle:migrate
```

## Scripts

- `pnpm drizzle:generate:raw`: Generate SQL migrations directly from `src/schema.ts`
- `pnpm drizzle:generate`: Generate migration and auto-add `DROP TABLE IF EXISTS` to newest SQL
- `pnpm drizzle:migrate`: Apply pending migrations to database
- `pnpm drizzle:studio`: Open Drizzle Studio
